# Estanislao Ran-Jel - Developer Application Portfolio

Dark themed React portfolio prepared for developer job applications. It includes resume-based profile content, downloadable resumes, technical skills, education, internship experience, and project work.

- PawFolio: https://pawfolio-five.vercel.app/
- Integrated Coffee Shop System: https://bleu-ums-zeta.vercel.app/
- Recipe Generator: https://recipe-no-db.vercel.app/

## Run Locally

```powershell
npm install
npm run dev
```

Then open the local URL Vite prints in the terminal.
